# Pamodzi Planner

A free, web-based daily planning tool designed to help individuals, students, professionals, and entrepreneurs organise their daily tasks, build productive habits, and track progress. Built as a community-driven initiative, the tool focuses on simplicity and effectiveness without overwhelming users with unnecessary features.

**Live ** [planner.site.je](https://planner.site.je)

---

## Features

- **7-Day Planning Window** – Plan tasks for each day of the week with an intuitive interface.
- **90-Day Task Expiry** – Tasks automatically expire after 90 days, encouraging consistent review and renewal.
- **Monthly Renewal** – Important tasks can be renewed each month to maintain focus on priorities.
- **40 Tasks Per Day Limit** – Designed to prevent overwhelm and promote realistic planning.
- **Free and Secure** – No hidden fees, no costs, and built with security in mind.
- **Community Driven** – Built for the community, by Pamodzi Brand.
